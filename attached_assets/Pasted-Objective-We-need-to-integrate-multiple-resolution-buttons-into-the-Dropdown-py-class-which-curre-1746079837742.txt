Objective:
We need to integrate multiple resolution buttons into the Dropdown.py class, which currently handles a dropdown list of resolution options. The goal is to enable users to select a resolution either by clicking a button (for each resolution) or by selecting it from the dropdown. This requires modifying the dropdown functionality to allow both button interactions and dropdown options in a seamless way.
Instructions:

    Dropdown Behavior:

        The Dropdown class currently works as a dropdown menu that displays a list of options when clicked. The user can select one option from the list.

        Add functionality to integrate multiple resolution buttons (e.g., for each resolution in RESOLUTIONS). The user should be able to click on one of the resolution buttons to select the resolution directly.

    Multiple Buttons Inside Dropdown:

        For each resolution (e.g., "1920x1080", "1280x720"), a button should appear within the dropdown, allowing users to click directly on a resolution to apply it.

        These buttons should be placed vertically inside the dropdown and have a similar appearance to the options listed in the dropdown.

        When a user clicks a button for a specific resolution, that resolution should be set as the selected option in the dropdown, and the dropdown should close immediately.

    Maintain Current Functionality:

        Keep the current dropdown functionality where users can still click on the dropdown to reveal the resolution options.

        Ensure that selecting an option from the dropdown (if not using the buttons) still updates the selected resolution correctly.

        When a button inside the dropdown is clicked, the resolution should be applied, and the dropdown should close.

    Dropdown State Management:

        Ensure that clicking on any button (either resolution button or dropdown button) toggles the is_open state of the dropdown, closing it when an option is selected.

        Ensure the dropdown can be opened and closed by clicking the main dropdown button.

    UI Updates:

        Ensure the UI layout is updated when the resolution changes, including re-scaling any UI elements to the new resolution.

Example Workflow:

    The user clicks the dropdown button (labeled "Resolution") to open the dropdown.

    The dropdown shows a list of resolution buttons (e.g., "1920x1080", "1280x720", etc.) and regular options.

    The user clicks a resolution button (or option) to select it.

    The selected resolution is applied, the screen is resized, and the dropdown closes.

Expected Outcome:

    A resolution dropdown that also includes clickable resolution buttons inside it.

    Selecting a resolution by either clicking the button or option should apply the resolution and close the dropdown.

Additional Notes:

    Ensure that the UI remains clean, with appropriate spacing between options and buttons.

    Ensure that when the dropdown is closed, the selected resolution (from button or dropdown) is shown on the dropdown button.
